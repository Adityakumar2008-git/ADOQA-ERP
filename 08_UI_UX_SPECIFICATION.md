# ADOQA ERP — UI/UX Specification v2

## Principle
Human-designed commercial ERP. Functional density without visual chaos.

## Owner ERP
- persistent sidebar
- contextual top bar
- page title
- filters
- action toolbar
- dense but readable tables
- clear status
- drawers/modals where useful
- desktop-first but responsive

## Staff
- mobile-first
- POS-centric
- minimal steps
- large touch targets
- fast scanner/search
- clear cart
- payment-first
- obvious success/failure

## Master Admin
- platform overview
- tenant/business monitoring
- subscription/partner operations
- financial metrics
- audit/log visibility

## Reusable Blade components
- button
- input
- select
- date range
- table
- pagination
- badge
- alert
- modal
- drawer
- card
- stat
- empty
- loading
- error
- confirmation
- sidebar
- topbar
- breadcrumbs
- money
- status
- form section

## Data UX
Every list:
- loading
- empty
- error
- pagination
- filters where needed

Every mutation:
- validation
- pending state
- success feedback
- failure feedback

## Accessibility
Keyboard navigation, labels, focus, semantic controls, readable contrast, accessible errors.

## Localization
English/Hindi-ready.

## No fake dashboard
Charts must have meaningful source data, date range and labels.
